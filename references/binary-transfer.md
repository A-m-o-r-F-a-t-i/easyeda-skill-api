# 文件传输边界

当前启用文本封装及已有有界二进制导出，未启用分块流端点。
PCB Info最大1MiB，DSN最大12MiB，源码哈希输入最大32MiB。制造工具另有默认8MiB、最多16MiB的本地文件上限。
读取File.size后再读取ArrayBuffer；UTF-8解码fatal并保留BOM，接收方还原字节后验证长度和SHA-256。

导出写入调用方指定的新文件路径，拒绝覆盖既有文件。临时文件校验完成后以同卷排他链接原子发布最终路径。
中途失败清理本次临时文件；若目标被其他进程创建，保留外部文件并返回OUTPUT_EXISTS。
不支持硬链接的目标文件系统应换本地受支持目录，不退化为无保护覆盖。
源哈希检查点没有工程内容，恢复仍需要实际EPRO备份。
