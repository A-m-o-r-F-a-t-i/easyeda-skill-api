# 事件、代次和执行恢复

Bridge每次进程启动生成bridgeGenerationId，Gateway每次连接建立或断开重置generationId。
图元/网络事件同步增加窗口epoch，回调不可靠携带文档UUID时不凭当前焦点归属；同窗口计划保守失效。
文档重新加载是否发出事件尚不完整，因此源哈希和对象旧值必须保留。
每个窗口保留512条事件，游标过旧显示截断，超前游标拒绝；generation不符不能继续增量读取。

生产写入在队列中核对完整目标、generation、epoch、源码哈希和操作旧值，逐操作读回。
无法提供原生编辑器事务锁；用户可以在调用期间编辑，应检查可观察变动并在不一致时停止后续写入。
执行记录保留成功和失败，容量满时拒绝新增记录，不驱逐不确定操作后再次执行。
相同executionId与内容再次到达返回原结果；重连后旧generation阻止旧请求重放。
