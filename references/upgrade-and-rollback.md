# 升级和回滚

先备份当前注册表、扩展包、Bridge启动方式和活动Skill版本。开发源码与已安装版本分离。
Bridge2先验证v1兼容，再安装独立身份的Enhanced Gateway；避免两个Gateway竞争同一窗口连接。
候选MCP只在隔离测试进程中发现和调用，生产配置一直保持一个稳定服务。
完成协议、解析、守卫和真实客户端回归后，切换同一个easyeda-pcb注册路径并读回实际版本与20工具清单。

API Skill与PCB Skill按新版本安装后激活，读取skill://资源确认。旧安装不可原地覆盖。
回滚按故障组件恢复之前的注册路径、Bridge脚本、扩展启用状态和活动Skill；关闭候选，不并行启用旧代工具。
PCB恢复使用实际内容备份或已核对的局部补偿，不用全局撤销覆盖用户编辑。
